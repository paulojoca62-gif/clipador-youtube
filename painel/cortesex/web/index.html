▶️ YouTube

Como configurar
  1. No Google Cloud, ative a YouTube Data API v3.
  2. Em Credenciais, crie um ID do cliente OAuth do tipo App para computador (ou Aplicativo da Web com o URI ).
  3. Na tela de consentimento, adicione o seu e-mail em Usuários de teste.
  4. Cole o ID e a chave aqui, salve e clique em Conectar canal.
  5. Sem a auditoria da API do Google, o YouTube pode travar os vídeos como privados.

🎵 TikTok

Como configurar
  1. Crie um app em developers.tiktok.com com Login Kit e Content Posting API (Direct Post ligado).
  2. Cadastre a Redirect URI (a mesma do campo acima).
  3. Sem a auditoria do TikTok, os vídeos saem privados e a conta precisa estar privada.

📘 Página do Facebook

Como configurar
  1. Crie um app do tipo Empresa em developers.facebook.com.
  2. No Explorador da Graph API, gere um token de usuário com pages_show_list, pages_read_engagement e pages_manage_posts.
  3. Cole aqui com o App ID e o App secret e clique em Buscar minhas Páginas. O token da Página escolhida não vence.
