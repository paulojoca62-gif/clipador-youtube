▶️ YouTube

Como configurar
  1. No Google Cloud, ative a YouTube Data API v3.
  2. Crie um ID do cliente OAuth do tipo App para computador (ou Aplicativo da Web com o URI ).
  3. Na tela de consentimento, adicione o seu e-mail em Usuários de teste.
  4. Sem a auditoria da API do Google, o YouTube pode travar os vídeos como privados.
