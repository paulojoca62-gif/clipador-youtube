# CortesEX-PRESS — Privacy Policy / Política de Privacidade

*Last updated / Atualizado em: November 19, 2026*

## English

CortesEX-PRESS runs entirely on the user's own computer. The owner of the application does not operate any server that receives user data.

**What the application handles**
- **Account access from TikTok, YouTube and Facebook.** When the user connects an account, the platform returns access tokens and basic profile information (for TikTok: the user's open ID, username and display name from the `user.info.basic` scope). These are used only to show which account is connected and to publish the user's clips with the `video.publish` scope (and the equivalent YouTube and Facebook permissions).
- **Clips and texts.** Video clips, titles, captions and hashtags created by the application.
- **Public live stream data.** Video and public chat messages from the Twitch channels the user chose to follow, used to detect highlights.

**Where it is stored.** Everything is stored locally on the user's computer (in the application's data folder). Tokens and keys are never sent to the owner of the application or to any third party, except to the platform they belong to.

**Who receives data.**
- TikTok, YouTube (Google) and Facebook (Meta) receive the clips and texts the user chooses to publish, through their official APIs.
- Google Gemini receives the transcript of a clip and a sample of public chat messages to write the title and caption, using the user's own API key.
- Telegram receives notification messages, only if the user enables them with their own bot.

**What it does not do.** It does not sell data, show ads, track users, or read private messages. It does not access TikTok data beyond the scopes listed above.

**Retention and deletion.** Clips are deleted automatically after the number of days set by the user. The user can disconnect any account in the application, which erases its tokens, revoke access in the platform's settings, or uninstall the application and delete its data folder to remove everything.

## Português

O CortesEX-PRESS roda inteiramente no computador do próprio usuário. O dono do aplicativo não mantém nenhum servidor que receba dados dos usuários.

**O que o aplicativo usa**
- **Acesso às contas do TikTok, YouTube e Facebook.** Ao conectar uma conta, a plataforma devolve tokens de acesso e informações básicas do perfil (no TikTok: open ID, nome de usuário e nome de exibição, pelo escopo `user.info.basic`). Isso serve só para mostrar qual conta está conectada e para publicar os cortes do usuário com o escopo `video.publish` (e as permissões equivalentes do YouTube e do Facebook).
- **Cortes e textos.** Os vídeos, títulos, legendas e hashtags criados pelo aplicativo.
- **Dados públicos das lives.** O vídeo e as mensagens públicas do chat dos canais da Twitch escolhidos pelo usuário, usados para detectar os melhores momentos.

**Onde fica guardado.** Tudo fica no computador do usuário, na pasta de dados do aplicativo. Tokens e chaves nunca são enviados ao dono do aplicativo nem a terceiros, só à plataforma a que pertencem.

**Quem recebe dados.**
- TikTok, YouTube (Google) e Facebook (Meta) recebem os cortes e textos que o usuário decide publicar, pelas APIs oficiais.
- O Google Gemini recebe a transcrição do corte e uma amostra das mensagens públicas do chat para escrever o título e a legenda, com a chave do próprio usuário.
- O Telegram recebe avisos, só se o usuário ligar essa opção com o próprio bot.

**O que ele não faz.** Não vende dados, não mostra anúncios, não rastreia usuários e não lê mensagens privadas. Não acessa dados do TikTok além dos escopos acima.

**Retenção e exclusão.** Os cortes são apagados sozinhos depois do número de dias definido pelo usuário. O usuário pode desconectar qualquer conta no aplicativo (o que apaga os tokens), revogar o acesso nas configurações da plataforma, ou desinstalar o aplicativo e apagar a pasta de dados para remover tudo.

**Contato:** https://github.com/paulojoca62-gif/clipador-youtube/issues
